# Inconvenient-Tetris-Browser-Extension-
A version of Tetris made to be incredibly inconvenient. This is built to be a browser extension.

***************************
Differences
***************************
 - Many more non-tetromino pieces added
 - Side screen warping (but one side shifts your block up by 1)
 - Random rotation point when you rotate a block
 - Any filled rows wait until the next block is placed to be cleared
